# Blog

Personal blog using [Next.js](https://nextjs.org/).

## Development env

- Node 18 or later

## Setup

```
git clone git@github.com:pietrop/pietrop.github.io.git
npm install
```

## Usage

For local development

```
npm run dev
```

## Build

```
npm run build
```

## Tests

```
npm test
```

## Deployment

The project can be deployed using any static hosting that supports Next.js outputs.
